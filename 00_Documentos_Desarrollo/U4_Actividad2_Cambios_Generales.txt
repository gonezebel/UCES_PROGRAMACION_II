1. Objetivo de la modificacion

Se amplio el sistema de turnos medicos desarrollado en Java Swing para cumplir
con la consigna de la Unidad 4 Actividad 2. El foco principal fue incorporar
componentes avanzados de interfaz grafica, reforzar el patron
Modelo-Vista-Controlador y agregar mejoras de uso en la aplicacion.


2. Organizacion del proyecto segun MVC

El proyecto quedo organizado en cuatro paquetes principales:

- modelo
- controlador
- vista
- principal

El paquete modelo contiene las clases del dominio del sistema, como Paciente,
Profesional, Especialidad, Agenda, Turno, Persona y Notificacion.

El paquete controlador contiene la logica de negocio y persistencia. La clase
principal de este paquete es SistemaTurnos, que administra altas, busquedas,
asignacion de turnos, anulacion de turnos, carga de datos y guardado de datos.
Tambien se agrego Autenticador para validar el ingreso al sistema.

El paquete vista contiene las interfaces de usuario. Ahi se ubican la ventana
Swing PrincipalApp, el dialogo LoginDialog, la vista de consola y la clase
IconoHospital.

El paquete principal contiene los puntos de entrada de la aplicacion. Desde ahi
se inicia la version grafica del sistema.


3. Pantalla de login

Se agrego una pantalla de login antes de mostrar la ventana principal. El

Credenciales configuradas para la entrega:

5. Componentes Swing incorporados

La interfaz usa distintos componentes de Swing para mejorar la experiencia del
usuario administrativo:

- JFrame para la ventana principal.
- JDialog para la pantalla de login.
- JOptionPane para mensajes, errores y confirmaciones.
- JCheckBox para filtrar agendas activas.
- JRadioButton y ButtonGroup para seleccionar el sexo del paciente.
- JList para seleccionar horarios disponibles.
- JTable para mostrar pacientes, profesionales, especialidades, agendas y
  turnos.
- JMenuBar, JMenu y JMenuItem para opciones de archivo y navegacion.
- JToolBar para accesos rapidos.
- JComboBox para seleccionar especialidades, profesionales, agendas y fechas.


6. Autoguardado y formularios pendientes

Las acciones principales del sistema guardan automaticamente los datos en los
archivos correspondientes. Esto evita que el usuario administrativo olvide
guardar luego de registrar una operacion. Por este motivo, cuando el usuario
presiona un boton de accion como Registrar, Asignar turno o Anular turno, la
operacion no queda solamente en memoria: se confirma y se persiste en el archivo
correspondiente.

Las acciones que autoguardan son:

- Registrar paciente.
- Registrar profesional.
- Registrar especialidad.
- Registrar agenda.
- Asignar turno.
- Anular turno.

Cada una de estas operaciones delega en SistemaTurnos y luego persiste el
resultado en los archivos:

- pacientes.txt
- profesionales.txt
- especialidades.txt
- agendas.xml
- turnos.xml

Tambien se conserva una opcion manual Guardar datos en el menu Archivo y en la
barra superior. Esta opcion permite forzar el guardado completo del estado
actual del sistema, aunque las operaciones principales ya se guardan
automaticamente.

La consulta al cerrar ya no se usa para datos registrados, porque esos datos se
guardan automaticamente. La advertencia aparece solamente si hay formularios con
campos cargados que todavia no fueron registrados. En ese caso, al cerrar o
recargar datos, el sistema informa que esos datos escritos en el formulario se
perderan si el usuario continua.

Ejemplo: si el usuario empezo a cargar un paciente pero no presiono Registrar
paciente, al intentar cerrar la aplicacion se muestra una advertencia. En cambio,
si el usuario ya presiono Registrar paciente, ese paciente ya fue guardado en el
archivo correspondiente.


7. Funcionalidades disponibles

La aplicacion permite realizar las siguientes operaciones:

- Registrar pacientes.
- Buscar pacientes por DNI.
- Registrar profesionales.
- Buscar profesionales por DNI.
- Registrar especialidades.
- Registrar agendas de atencion.
- Consultar agendas por dia y especialidad.
- Buscar paciente para asignar turno.
- Seleccionar especialidad, profesional, agenda, fecha y horario disponible.
- Asignar turnos.
- Buscar turnos por paciente.
- Anular turnos vigentes.
- Recargar datos desde archivos.
- Guardar datos en archivos.
- Ingresar mediante login.
- Advertir al cerrar o recargar si quedan formularios a medio completar.
