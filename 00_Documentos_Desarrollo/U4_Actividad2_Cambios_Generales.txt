1. Objetivo de la modificación

Se amplió el sistema de turnos médicos desarrollado en Java Swing para cumplir
con la consigna de la Unidad 4 Actividad 2. El foco principal fue incorporar
componentes avanzados de interfaz gráfica, reforzar el patrón
Modelo-Vista-Controlador y agregar mejoras de uso en la aplicación.


2. Organización del proyecto según MVC

El proyecto quedó organizado en cuatro paquetes principales:

- modelo
- controlador
- vista
- principal

El paquete modelo contiene las clases del dominio del sistema, como Paciente,
Profesional, Especialidad, Agenda, Turno, Persona y Notificación.

El paquete controlador contiene la lógica de negocio y persistencia. La clase
principal de este paquete es SistemaTurnos, que administra altas, búsquedas,
asignación de turnos, anulación de turnos, carga de datos y guardado de datos.
También se agregó Autenticador para validar el ingreso al sistema.

El paquete vista contiene las interfaces de usuario. Ahí se ubican la ventana
Swing PrincipalApp, el diálogo LoginDialog, la vista de consola y la clase
IconoHospital.

El paquete principal contiene los puntos de entrada de la aplicación. Desde ahí
se inicia la versión gráfica del sistema.


3. Pantalla de login

Se agregó una pantalla de login antes de mostrar la ventana principal. El
objetivo es simular un ingreso administrativo al sistema de turnos.

Credenciales configuradas para la entrega:

- Usuario: admin
- Clave: admin123

La pantalla de login utiliza campos de texto y contraseña, botones de ingreso y
cancelación, y un mensaje de estado cuando las credenciales no son correctas.
La validación no queda en la vista, sino en el controlador Autenticador.

5. Componentes Swing incorporados

La interfaz usa distintos componentes de Swing para mejorar la experiencia del
usuario administrativo:

- JFrame para la ventana principal.
- JDialog para la pantalla de login.
- JOptionPane para mensajes, errores y confirmaciones.
- JCheckBox para filtrar agendas activas.
- JRadioButton y ButtonGroup para seleccionar el sexo del paciente.
- JList para seleccionar horarios disponibles.
- JTable para mostrar pacientes, profesionales, especialidades, agendas y
  turnos.
- JMenuBar, JMenu y JMenuItem para opciones de archivo y navegación.
- JToolBar para accesos rápidos.
- JComboBox para seleccionar especialidades, profesionales, agendas y fechas.


6. Autoguardado y formularios pendientes

Las acciones principales del sistema guardan automáticamente los datos en los
archivos correspondientes. Esto evita que el usuario administrativo olvide
guardar luego de registrar una operación. Por este motivo, cuando el usuario
presiona un botón de acción como Registrar, Asignar turno o Anular turno, la
operación no queda solamente en memoria: se confirma y se persiste en el archivo
correspondiente.

Las acciones que autoguardan son:

- Registrar paciente.
- Registrar profesional.
- Registrar especialidad.
- Registrar agenda.
- Asignar turno.
- Anular turno.

Cada una de estas operaciones delega en SistemaTurnos y luego persiste el
resultado en los archivos:

- pacientes.txt
- profesionales.txt
- especialidades.txt
- agendas.xml
- turnos.xml

También se conserva una opción manual Guardar datos en el menú Archivo y en la
barra superior. Esta opción permite forzar el guardado completo del estado
actual del sistema, aunque las operaciones principales ya se guardan
automáticamente.

La consulta al cerrar ya no se usa para datos registrados, porque esos datos se
guardan automáticamente. La advertencia aparece solamente si hay formularios con
campos cargados que todavía no fueron registrados. En ese caso, al cerrar o
recargar datos, el sistema informa que esos datos escritos en el formulario se
perderán si el usuario continúa.

Ejemplo: si el usuario empezó a cargar un paciente pero no presionó Registrar
paciente, al intentar cerrar la aplicación se muestra una advertencia. En cambio,
si el usuario ya presionó Registrar paciente, ese paciente ya fue guardado en el
archivo correspondiente.


7. Funcionalidades disponibles

La aplicación permite realizar las siguientes operaciones:

- Registrar pacientes.
- Buscar pacientes por DNI.
- Registrar profesionales.
- Buscar profesionales por DNI.
- Registrar especialidades.
- Registrar agendas de atención.
- Consultar agendas por día y especialidad.
- Buscar paciente para asignar turno.
- Seleccionar especialidad, profesional, agenda, fecha y horario disponible.
- Asignar turnos.
- Buscar turnos por paciente.
- Anular turnos vigentes.
- Recargar datos desde archivos.
- Guardar datos en archivos.
- Ingresar mediante login.
- Advertir al cerrar o recargar si quedan formularios a medio completar.
